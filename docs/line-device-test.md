### 0.3 live にしたときの影響

- 友だちが送ったメッセージに、自動応答 OFF の定型文が**実際に返信される**（返信は無料）
- 自動応答 OFF の間は、すべての受信が要対応になり、**オーナー通知（push・有料枠）が送られる**（10 分間隔・1 日 5 通まで）。live のまま放置すると、受信がある日は最大 5 通ずつ使う（30 日で最大 150 通）。**テストが終わったら dry-run に戻す**
- 未通知の 1 件は、live にした後の最初の通知に含まれる

### 0.4 AC-23「オーナーにだけ届く」の確かめ方

- 推奨：**2 つ目の LINE アカウント**（家族の端末や予備のアカウント。実在のお客様は使わない）を、テストの間だけ友だち追加する。テスト送信がそのアカウントに届かないことを確認する
- 2 つ目がない場合：オーナーに届くこと、使用数がちょうど 1 増えることを確認する。ただし友だちがオーナー 1 人だけでは、全員への配信と区別できないため、「オーナーにだけ」の部分は**自動テスト（宛先はオーナーの ID だけ）で代替**したと記録する
- **2026-11-14 決定：2 つ目のアカウントは用意せず、オーナーのアカウント 1 つで行う。** 記録は次のとおりにする
  - 実機で確認する：オーナーの LINE にテスト送信が届くこと、LINE の使用数がテスト送信で 1 だけ増えること、配信の状態が「テスト送信済み」になること（配信済みにはならないこと）
  - 自動テストで補う：宛先がオーナーの ID だけで、一斉配信の API を使わないこと（`tests/admin/broadcast-actions.test.ts`「オーナーにだけ push し、テスト送信済みにする」）
  - **実機では未確認**：オーナー以外の友だちに届かないこと（友だちがオーナー 1 人のため、実機では確かめられない）

### 0.5 環境変数の切り替え（再デプロイは有効化と復旧の 2 回だけ）

テストの前（値はどれも秘密ではないため、`--value` で指定してよい）：

```powershell
Set-Location 'C:\path\to\salon-line-bot'   # このリポジトリのフォルダに置き換える
function vc { npx vercel@65.15.0 @args }
vc env update LINE_REPLY_MODE --environment production --value live      # 確認に y
vc env add ADMIN_WRITE_MODE --environment production --type config --value enabled
vc env add LINE_BROADCAST_MODE --environment production --type config --value live
vc env ls production                                                     # 13 項目。ANTHROPIC_API_KEY・ADMIN_ANSWER_TEST_MODE がないこと
vc deploy --prod
```

テストの後（元に戻す）：

```powershell
vc env update LINE_REPLY_MODE --environment production --value dry-run   # 確認に y
vc env rm ADMIN_WRITE_MODE --environment production                      # 変数名を入力して確認
vc env rm LINE_BROADCAST_MODE --environment production
vc env ls production                                                     # 11 項目に戻ること
vc deploy --prod
```

- `ANTHROPIC_API_KEY`・`ADMIN_ANSWER_TEST_MODE` は登録しない（AI は呼ばない）。`bot_enabled` は変えない
- 書き込みが有効な間は、管理画面のどの保存ボタンも使える。テストで使うのは「お知らせ配信」の下書き・テスト送信・削除だけ。ほかの画面では保存しない（AC-22 を同時に行う場合は別途承認）
- 緊急時：Vercel の Deployments で直前のデプロイに **Instant Rollback** すると、そのデプロイの環境変数（dry-run・安全スイッチなし）で動く（Hobby で戻せる範囲は**要確認**。確実なのは「テストの後」の手順）。または自動応答とは別に、LINE Developers で「Webhook の利用」を OFF にすると受信が止まる

## 3. 手順

### AC-07：スタンプ・画像への応答

1. お客様役の LINE から、公式アカウントに**スタンプを 1 つ**送る。
2. 続けて**画像を 1 枚**送る（写真は人物・個人情報が写っていないもの）。
3. 確認すること：
   - お客様役の LINE に、それぞれ定型文が返ってくる（自動応答 OFF のため、店舗情報の「自動応答 OFF のときの定型文」が返る）。
   - エラーの表示や無応答がない。返ってくるまでの時間（目安：数秒）を記録する。
   - 管理画面の「会話ログ」に 2 件記録されている（種類はスタンプ・画像）。
   - オーナー役の LINE に、オーナー通知が届く（10 分以内の 2 件は 1 通にまとまる。届かない場合は 15 分ごとの定期実行で届く）。
   - `npm run check:webhook-events -- --since <テスト開始の日時>`（読み取り専用）で、2 件とも処理済み・返信 `sent` になっている。
4. 参考：自動応答が ON のときは「画像やスタンプなどには自動でお答えできません。お手数ですが、文章でお問い合わせください。」が返る（AI は呼ばない）。**ON での確認は、初期データの登録と承認の後に行う**（この手順では行わない）。

### AC-23：オーナーへのお知らせのテスト送信

1. 管理画面にログインし、「お知らせ配信」→「新しいお知らせ（下書き）」に、次のような本文を入力して保存する。
   `【テスト】お知らせ配信のテストです。このメッセージはオーナーにだけ届きます。`
2. 確認画面で「**オーナーにテスト送信**」を 1 回だけ押す。
3. 確認すること：
   - オーナー役の LINE に「【テスト送信】次の内容を友だち全員に配信する予定です。」と本文の 2 つの吹き出しが届く（1 回の送信にまとめているため、通数は 1 通）。
   - **お客様役の LINE には届かない**（数分待って確認する）。
   - 配信の状態が「テスト送信済み」になり、「2. 配信（友だち全員に送ります）」の欄が表示される。
   - テスト送信のボタンは押すたびに送信される（1 通ずつ消費する）ため、2 回以上は押さない。

### AC-24：一斉配信の確認画面（**配信はしない**）

1. AC-23 の下書きの確認画面で、「2. 配信」の欄を確認する。
2. 確認すること：
   - **配信対象数**（友だちの数。前日時点の目安）が表示される。テスト時点では 2 前後（オーナー役・お客様役）。
   - **今月の残り送信可能数**と、**配信後の残り見込み**が表示される。LINE 公式アカウントの管理画面の通数と大きく違わないこと。
   - 確認の欄に「確認のため「配信する」と入力」と表示されている。
   - （任意）確認の欄を**空のまま**「友だち全員に配信する」を 1 回押すと、「確認のため「配信する」と入力してください。」と表示され、配信されない（状態は「テスト送信済み」のまま、お客様役の LINE に何も届かない）。
3. **確認の欄に「配信する」とは絶対に入力しない。** 入力して押すと、友だち全員に配信される。
4. 確認が終わったら、下書きを「削除する（元に戻せません）」で削除する。

### 後片付け

1. Vercel の環境変数を元に戻す（`LINE_BROADCAST_MODE`・`ADMIN_WRITE_MODE` を削除。運用を始めない場合は `LINE_REPLY_MODE` も `dry-run` に戻す）→ 再デプロイ。
2. LINE 公式アカウントの管理画面で、今月のメッセージ通数が想定どおり（2〜3 通）増えていることを確認する。
3. 会話ログのテストの記録は、90 日で自動的に削除される（手で消す必要はない）。
