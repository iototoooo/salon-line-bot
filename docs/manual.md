# 運用マニュアル（オーナー向け）：美容室LINE自動応答システム

- 版数：v1.0（2026-11-13）
- 対象：お店のオーナー（管理者）。パソコンやスマートフォンのブラウザから操作します。
- 関連資料：保守担当者向けの設定は [deployment.md](./deployment.md)、仕組みの詳細は [architecture.md](./architecture.md)

---

## 0. このシステムでできること

| できること | 説明 |
|---|---|
| LINE の自動応答 | お客様からの質問に、登録した FAQ・メニュー・店舗情報だけをもとに AI が自動で答えます |
| 答えられない質問のお知らせ | AI が答えられなかった質問は「確認してご連絡します」と返し、オーナーの LINE にお知らせします |
| 管理画面 | FAQ・料金・店舗情報の更新、会話の確認、自動応答の停止、お知らせの一斉配信ができます |

**大切なこと**

- AI は**予約の空き状況には答えません**。予約に関する質問には、登録した「予約方法の案内」をそのまま返します。
- AI は**登録されていない情報を推測して答えません**。答えられない質問は「確認が必要です」と返し、オーナーの対応が必要な一覧に入ります。
- 料金は「メニュー・料金」に登録した金額だけを案内します。AI が合計や割引を計算することはありません。

## 1. ログイン・ログアウト

### ログイン

1. ブラウザで管理画面のアドレス（保守担当者から案内された `https://…/login`）を開きます。
2. **メールアドレス**と**パスワード**を入力し、「**ログイン**」を押します。
3. 「ホーム」画面が表示されたらログイン完了です。

- 「メールアドレスまたはパスワードが正しくありません。」と表示されたら、入力内容を確認してください。管理者として登録されていないアカウントでも、同じメッセージになります。
- ログインしていない状態で管理画面のページを開くと、自動でログイン画面に移動します。ログイン後は、開こうとしたページに戻ります。
- パスワードは他の人に教えず、パスワード管理ツールなどで保管してください。

### ログアウト

画面右上の「**ログアウト**」を押します。共用のパソコンでは、使い終わったら必ずログアウトしてください。

---

## 2. 画面の見方

画面上部のメニューから、各画面に移動します。

| メニュー | 内容 |
|---|---|
| ホーム | 未対応のお問い合わせの件数、自動応答の ON/OFF、通知先の設定状況、FAQ・メニューの登録件数 |
| 未対応一覧 | オーナーの対応が必要なお問い合わせ |
| 会話ログ | お客様とのやり取りの記録（90 日分） |
| FAQ | よくある質問と回答の登録・編集 |
| メニュー・料金 | メニューと料金の登録・編集 |
| 店舗情報・設定 | 店舗情報、自動応答の ON/OFF、通知の送り先 |
| 回答テスト | LINE に送らずに、AI がどう答えるかを試す |
| お知らせ配信 | 臨時休業などを友だち全員に配信する |

画面の上に黄色の「安全のため、次の操作は無効になっています」が表示されている場合、その操作はサーバーの設定で止められています。必要な場合は保守担当者に連絡してください（[9. トラブル時の対応](#9-トラブル時の対応)）。

## 3. FAQ（よくある質問）

AI は、**公開中の FAQ** だけを回答の根拠にします。回答はお客様にそのまま伝わる文章で書いてください。

### 追加する

1. 「FAQ」を開きます。
2. 「**FAQ を追加**」の欄に入力します。
   - **質問**（300 文字まで）：例「パーマとカラーは同時にできますか？」
   - **回答**（2,000 文字まで）：例「同じ日に施術できます。所要時間は 3 時間ほどです。」
   - **分類**：営業時間・定休日／料金／予約／施術／アクセス・駐車場／その他
   - **表示順**：小さい数字ほど上に並びます
   - **公開する（AI の回答に使う）**：チェックを外すと、登録はされますが AI は使いません
3. 「**追加する**」を押します。「FAQ を追加しました。」と表示されれば完了です。

> 料金は FAQ に書かず、「メニュー・料金」に登録することをおすすめします（料金の変更が 1 か所で済みます）。

### 編集・公開の切り替え・削除

1. 対象の FAQ の「**編集・公開切り替え・削除**」を押して開きます。
2. 内容を直して「**保存する**」を押します。
3. 一時的に AI に使わせたくない場合は「**非公開にする**」を、戻すときは「**公開する**」を押します。
4. 削除する場合は「**削除する（元に戻せません）**」にチェックを入れてから「**削除**」を押します。チェックがないと削除されません。

## 4. メニュー・料金

料金は**税込・円・整数**で登録します。変更は**次のお問い合わせから**反映されます（再設定や再起動は不要です）。

### 追加する

1. 「メニュー・料金」を開き、「**メニューを追加**」の欄に入力します。
   - **メニュー名**：例「カット」「カット＋カラー」
   - **分類**：カット／カラー／パーマ／トリートメント／セット／その他
   - **料金（税込・円）**：例「4400」（「４，４００」のような全角数字・カンマも入力できます。小数は入力できません）
   - **料金の補足**：例「ロング +1,100円」（ここに書いた金額も AI の案内に使われます）
   - **所要時間（分）**・**説明**・**表示順**：必要に応じて
   - **公開する（AI の回答に使う）**
2. 「**追加する**」を押します。

### 料金を改定するとき

1. 対象のメニューの「**編集・公開切り替え・削除**」を開きます。
2. 料金を直して「**保存する**」を押します。一覧の金額が変わったことを確認します。
3. 「回答テスト」で「カットはいくらですか？」などと試し、新しい料金で答えるか確認すると安心です（[7. 回答テスト](#7-回答テスト)）。

削除は FAQ と同じく、「削除する（元に戻せません）」にチェックを入れてから「削除」を押します。

## 5. 店舗情報・自動応答・通知先（「店舗情報・設定」画面）

### 店舗情報

店名・営業時間・定休日・住所・電話番号・駐車場・予約方法の案内・臨時のお知らせ・定型文を入力し、「**保存する**」を押します。

| 項目 | 使われ方 |
|---|---|
| 予約方法の案内 | 空き状況や予約について聞かれたとき、AI の文章ではなく**この文章をそのまま**返します。電話番号や予約ページのアドレスを書いてください |
| 臨時のお知らせ | 臨時休業など。AI の回答の根拠にも使われます。**不要になったら空欄に戻して**ください |
| 定型文（自動応答 OFF・エラー時） | 自動応答を OFF にしているときや、エラーが起きたときに返す文章です（必須） |

### 自動応答の ON/OFF（緊急停止スイッチ）

- **OFF** にすると、AI を使わず、上の「定型文」だけを返します。AI の回答に誤りが続く場合などに使います。
- 切り替え方：確認の欄に「**変更する**」と入力してから、「自動応答を OFF にする」（または「自動応答を ON にする」）を押します。「変更する」以外の文字では切り替わりません。
- **ON にする前に**、FAQ・メニュー・店舗情報が正しく登録されているかを確認してください。

### オーナー通知の送り先（LINE）

答えられなかった質問などを、オーナーの LINE にお知らせする宛先です。

1. LINE Developers コンソールのチャネルの「基本設定」にある「**あなたのユーザーID**」（U で始まる 33 文字）を確認します。
2. 「**LINE ユーザー ID**」の欄に入力し、「**保存する**」を押します。
3. 「設定済み」と表示されれば完了です。安全のため、**登録した ID は画面に表示されません**。
4. 通知を受け取るには、オーナーの LINE で**このお店の LINE 公式アカウントを友だち追加**しておく必要があります。
5. 通知を止めたい場合は「**通知先を解除する**」にチェックを入れて「保存する」を押します（通知は送られず、未対応一覧にだけ表示されます）。

## 6. 未対応一覧・会話ログ

### オーナー通知の内容

答えられなかった質問があると、オーナーの LINE に次のようなお知らせが届きます。

```
【要対応】LINE のお問い合わせ 2 件
・11/12 14:32 確認が必要な質問「〇〇のシャンプーは売って…」
・11/12 14:40 画像・スタンプなど
未対応一覧：https://…/admin/inbox
```

- 送りすぎを防ぐため、**10 分以内のお問い合わせは 1 通にまとめ**、**1 日 5 通まで**にしています。上限を超えた分は翌日の 1 通にまとめて届きます（すべて未対応一覧には表示されています）。
- AI の利用上限に達したときは、【重要】の通知が 1 日 1 回届きます。
- お知らせにはお客様の名前や LINE ユーザー ID は含まれません。

### 未対応一覧での対応

1. 「未対応一覧」を開きます（通知のリンクからも開けます）。
2. お問い合わせの内容を確認します。お客様は「お客様 #xxxxxx」という記号で表示されます（同じ記号なら同じお客様です）。
3. LINE 公式アカウントのチャット画面（LINE Official Account Manager）から、お客様に返信します。
4. 返信が済んだら「**対応済みにする**」を押します。一覧から消え、会話ログに「対応済み」と記録されます。

### 会話ログ

- お客様とのやり取りの記録です。**日付**と「**未対応のみ**」で絞り込めます（「絞り込む」を押す）。
- 保存期間は 90 日です。90 日を過ぎた記録は、毎日深夜（3 時ごろ）に自動で削除されます（未対応のままでも削除されます。必要な内容は早めに確認してください）。
- よく聞かれるのに AI が答えられない質問があれば、FAQ に追加してください。

## 7. 回答テスト

LINE に送らずに、登録した情報で AI がどう答えるかを確認できます。会話ログには保存されません。

1. 「回答テスト」を開き、お客様の質問を入力して「**回答を確認する**」を押します。
2. 「お客様に返る文章」「判定」「オーナー対応の要否」「根拠の件数」が表示されます。

- 「現在は AI を呼び出しません」と表示されている場合は、AI を使わない設定です（費用はかかりません）。質問が長すぎる・登録情報が空、などの事前の判定だけを確認できます。
- AI を使う設定の場合は、1 回ごとに Claude API の費用がかかります（1 時間に 20 回まで）。

## 8. お知らせ配信（一斉配信）

臨時休業などのお知らせを、LINE の**友だち全員**に送ります。誤送信を防ぐため、次の順番でしか配信できません。

> **注意**：配信は友だちの人数分の送信数を使います（無料プランは月 200 通まで。オーナーへの通知も同じ枠を使います）。

1. **下書き**：「お知らせ配信」を開き、「新しいお知らせ（下書き）」に本文（5,000 文字まで）を入力して「**下書きを保存**」を押します。確認画面に移ります。
2. **プレビュー**：LINE での見え方の目安を確認します。直す場合は「本文の編集」で直して「本文を保存」を押します（本文を変えると、テスト送信からやり直しになります）。
3. **テスト送信**：「**オーナーにテスト送信**」を押すと、オーナーの LINE にだけ届きます。内容をスマートフォンで確認してください。
4. **送信数の確認**：「2. 配信」の欄に、配信対象（前日時点の目安）・今月の残り送信可能数・配信後の残り見込みが表示されます。**残りが足りない場合は配信できません**（追加料金を防ぐため）。
5. **配信**：確認の欄に「**配信する**」と入力し、「**友だち全員に配信する**」を押します。ボタンを何度押しても、配信は 1 回だけです。
6. **履歴**：「お知らせ配信」の一覧で、配信済み・失敗などの状態を確認できます。

- 下書きとテスト送信済みの配信は、「削除する（元に戻せません）」にチェックを入れて削除できます。
- 「失敗・結果不明」と表示された場合は、[9. トラブル時の対応](#9-トラブル時の対応) を見てください。

## 9. トラブル時の対応

| 困ったこと | まず行うこと | それでも解決しないとき |
|---|---|---|
| **AI の回答が間違っている・おかしい** | すぐに「店舗情報・設定」で**自動応答を OFF**（確認の欄に「変更する」）。定型文だけが返るようになります | 該当する FAQ・メニュー・店舗情報を直し、「回答テスト」で確認してから ON に戻す |
| 料金を変えたのに古い料金で答える | 「メニュー・料金」で金額と「公開中」かを確認。料金の補足や FAQ に古い金額が書かれていないか確認 | 保守担当者に連絡 |
| オーナー通知が届かない | 「店舗情報・設定」で通知先が「設定済み」か、オーナーの LINE で公式アカウントを友だち追加しているか（ブロックしていないか）を確認 | 未対応一覧には表示されているので、一覧で対応する。保守担当者に連絡 |
| ログインできない | メールアドレス・パスワードを確認 | 保守担当者に連絡（パスワードの再設定は保守担当者が行います） |
| 保存ボタンが押せない（「保存・変更」が無効と表示） | サーバーの設定で書き込みが止められています | 保守担当者に連絡 |
| 配信が「失敗・結果不明」になった | **LINE 公式アカウントの管理画面で、配信されたかどうかを先に確認**してください | 配信されていなければ、23 時間以内なら同じ画面から再度「配信する」を押せます（届いていた場合でも二重には届きません）。23 時間を過ぎた場合は新しい下書きを作ってください |
| 配信が「送信中」のまま変わらない | LINE 公式アカウントの管理画面で配信履歴を確認 | 保守担当者に連絡（状態を直す作業が必要です） |
| 送信可能数が足りず配信できない | 翌月まで待つか、配信をやめる | 有料プランへの変更は費用がかかるため、契約内容を確認してから判断してください |
| お客様から「返事が来ない」と言われた | 会話ログで、そのお問い合わせの記録を確認 | 保守担当者に連絡 |

**緊急時の最優先の操作は「自動応答を OFF」です。** OFF にしても LINE の受付は続き、お客様には定型文が返り、未対応一覧に記録されます。

## 10. 保守担当者への連絡事項（オーナーは読み飛ばして構いません）

- 管理画面の保存・LINE 送信・AI 回答テストは、サーバーの環境変数（`ADMIN_WRITE_MODE`・`LINE_BROADCAST_MODE`・`ADMIN_ANSWER_TEST_MODE`）で有効にします。既定はすべて無効です。設定方法は [deployment.md](./deployment.md)。
- 管理者アカウントの追加・削除、パスワードの再設定は Supabase のダッシュボードで行います（新規登録は無効のまま）。
- 定期実行（未送信の通知・停止したイベントの確認）は 15 分ごと、古い記録の削除は毎日 3 時ごろです（Vercel Schedules）。
