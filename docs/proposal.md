## 1. いま困っていること

- LINE のお問い合わせが **1日10〜15件** 届き、施術の合間や営業後に一件ずつ返信している
- そのうち多くは **「営業時間は？」「カットはいくら？」「予約できますか？」「パーマとカラーは一緒にできますか？」「駐車場はありますか？」** といった、毎回同じ答えになる質問
- 返信が遅れると、お客様が他のお店を選んでしまうおそれがある
- 臨時休業などのお知らせを、友だち（約300人）へ確実に、まちがいなく届けたい

## 2. ご提案の内容

**いまお使いの LINE 公式アカウントに、AI の自動応答を追加します。** お客様の LINE アプリや友だち登録はそのままです。

| できること | 内容 |
|------------|------|
| よくある質問に AI がすぐ返信 | 夜間や施術中でも、営業時間・料金・駐車場などに数秒〜十数秒で返信します |
| お店の情報だけで答える | AI は、オーナー様が管理画面に登録した内容（FAQ・料金表・店舗情報）**だけ**をもとに答えます。書かれていないことは推測で答えません |
| 答えられない質問はオーナー様へお知らせ | AI が答えられない質問は、お客様に「確認してご連絡します」と返し、オーナー様の LINE にお知らせが届きます |
| 予約の空き状況は答えません | 空き状況を AI が勝手に答えると、ダブルブッキングなどの原因になります。予約のご質問には「お電話（または予約ページ）でお願いします」と案内します |
| 料金変更はオーナー様ご自身で | 半年に1回程度の料金改定も、管理画面で数字を変えるだけ。すぐに AI の回答に反映されます |
| お知らせの一斉配信 | 臨時休業などを管理画面から配信できます。**送る前にご自身の LINE で見え方を確認**し、**配信人数と今月の送信可能数**を確認したうえで送る仕組みにします |
| 困ったときの停止ボタン | もし AI の回答がおかしいと感じたら、管理画面のボタン1つで AI を止め、「担当者からご連絡します」という定型文だけに切り替えられます |

## 3. 期待できる効果

> 数値は一般的な想定にもとづく目安で、効果を保証するものではありません。

- **返信の手間が減る**：問い合わせのうち、よくある質問（全体の半分〜7割程度と想定）を AI が対応。1件あたり3〜5分の返信作業とすると、**1日あたり約20〜50分**の時間を施術や接客にあてられます
- **お客様を待たせない**：夜間・定休日でもすぐに返事が届き、予約の検討から来店までがスムーズになります
- **取りこぼしの防止**：AI が答えられなかった質問は必ずオーナー様にお知らせが届き、管理画面に「未対応」として残ります
- **お知らせの誤送信防止**：確認手順を仕組みとして組み込むため、誤った内容の一斉送信を防げます

## 4. 使う技術（仕組みのイメージ）

```
お客様の LINE → LINE 公式アカウント → 自動応答プログラム（Vercel） → AI（Claude）
                                              ↕
                                     お店の情報の保管庫（Supabase）
                                              ↕
                                     オーナー様用の管理画面（パソコン・スマホ）
```

| 名前 | ひとことで言うと |
|------|------------------|
| LINE Messaging API | LINE 公式アカウントとプログラムをつなぐ LINE 社の公式の仕組み |
| Claude API | 文章を理解して返事を作る AI（Anthropic 社） |
| Supabase | FAQ・料金表・やりとりの記録を保管するデータベース |
| Vercel | プログラムと管理画面を動かすサーバー |
| Next.js | 管理画面とプログラムを作るための道具 |

各サービスのアカウントは **お店（オーナー様）名義** で作成していただき、開発者は作業用に招待していただく形をおすすめします。費用の支払いが透明になり、将来ほかの業者に保守を依頼する場合もスムーズです。

### 5.2 月額費用（目安）

> **重要：以下の金額・無料枠は、本提案書作成時点で各社の公式情報による最新確認ができていません（未確認）。** ご契約前に最新の料金を確認し、確定版をお出しします。為替（ドル建てのサービス）によっても変動します。

| 項目 | 内容 | 月額の目安 | 状態 |
|------|------|------------|------|
| LINE 公式アカウント | お客様への返信は「応答メッセージ」を使うため、送信数に数えられない想定。一斉配信とオーナー様への通知は送信数に数えられる想定 | 0円（無料プラン）〜 有料プラン | **未確認** |
| AI（Claude API） | 月300〜450件の問い合わせ、軽量モデル利用の想定 | 数百円〜1,000円程度 | **未確認**（実測で確定） |

| 保守サポート（任意） | FAQ 追加代行、障害対応など | 別途ご相談 | — |

**前提条件**

1. 問い合わせ件数は1日10〜15件（月450件程度まで）
2. 一斉配信は月1〜2回程度
3. **LINE の無料プランの送信数は、友だち300人に1回配信するだけで上限を超える可能性があります（未確認）。** 配信を定期的に行う場合は LINE 公式アカウントの有料プランが必要になる場合があります。本システムでは、送信可能数を超える配信はボタンが押せないようにして、思わぬ追加費用を防ぎます
4. オーナー様への通知は、件数をまとめて送ることで送信数を節約します
5. AI の利用料には上限額を設定し、想定外の高額請求を防ぎます

## 8. ご注意いただきたいこと

- AI は登録内容にもとづいて回答しますが、**まれに不正確な返答をする可能性はゼロではありません**。会話の記録はいつでも管理画面で確認でき、気になる場合は停止ボタンで AI を止められます
- お客様とのやりとりは記録として保存します（初期設定は90日で自動削除）。お店のプライバシーポリシーへの記載をお願いします
- 料金表・営業情報が変わった際は、管理画面での更新をお願いします（AI は登録内容をそのまま案内します）
