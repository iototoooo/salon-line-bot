## 2. GitHub 公開の方針（2026-11-14 決定）

- 公開用に、**独立した 1 コミットの履歴**を作る（元のローカルの Git 履歴は保持し、書き換えない）。コミットの作者は GitHub の noreply アドレスにする（元の履歴のコミットには個人のメールアドレスが含まれるため）
- 公開前の確認（2026-11-14・読み取りのみ）：追跡中のファイルと全履歴に、本物の API キー・トークン・秘密鍵・LINE ユーザー ID・Vercel の ID は含まれていない（検出されたのはテスト用のダミーだけ）。個人の Windows のパスは手順書から取り除いた
- 本番の Supabase の Ref・公開 URL は秘密ではない（キーはリポジトリに含めず、DB は RLS で保護）ため、資料に残す

## 3. Claude API の実接続と、主要 5 問のテスト（2026-11-14 実施・合格）

**必要な設定**（実施する場合。課金が発生する）

1. Anthropic Console で API キーを作り、**月の利用上限額を設定する**
2. Vercel の Production に `ANTHROPIC_API_KEY`（Secret）と `ADMIN_ANSWER_TEST_MODE=live`（Config）を登録して再デプロイ（`CLAUDE_MODEL` は空欄でよい。既定は `claude-haiku-5-5`）
3. 自動応答は OFF、返信は dry-run のまま。管理画面の「回答テスト」で確認する（LINE には送らない。回答テストは 1 時間に 20 回まで）
4. 終わったら `ADMIN_ANSWER_TEST_MODE` を削除して再デプロイ（API キーも不要なら削除）

**主要 5 問**（架空店舗のデータで判定）

| AC | 質問 | 合格の条件 |
|---|---|---|
| AC-01 | 営業時間を教えてください | 平日 10:00〜19:00、土日祝 9:00〜18:00 と答える |
| AC-02 | カットはいくらですか？ | 4,400 円と答え、ほかの金額を出さない |
| AC-03 | 明日の 10 時に予約できますか？ | 空きを断定せず、登録した予約方法の案内を返す |
| AC-04 | 白髪染めはできますか？ | FAQ のとおり（カラーとリタッチカラーの案内） |
| AC-05 | 駐車場はありますか？ | 専用駐車場はなく、近隣のコインパーキングを案内する |

- 呼び出しは 5 回。費用は Anthropic の料金表で確認する（ここでは推測しない）
- 回答テストは、LINE の受信時と同じ回答処理（`generateAnswer`）を通るが、LINE を経由しない確認であることを記録に明記する

### 実施結果（2026-11-14）

- 上記の設定（`ANTHROPIC_API_KEY`・`ADMIN_ANSWER_TEST_MODE=live` を Production に登録して再デプロイ）で、管理画面の「回答テスト」から実際の Claude API を呼び出した（オーナー役の開発者が実施）
- **5 問すべて合格**

| AC | 質問 | 結果 |
|---|---|---|
| AC-01 | 営業時間 | 合格：平日 10〜19 時、土日祝 9〜18 時。定休日も正確 |
| AC-02 | カットの料金 | 合格：4,400 円（税込） |
| AC-03 | 予約 | 合格：空き状況を断定せず、スタッフへの確認（予約方法）を案内 |
| AC-04 | 白髪染め | 合格：カラー・リタッチカラーを案内 |
| AC-05 | 駐車場 | 合格：専用駐車場はなく、近隣のコインパーキングを案内 |

- **確認の範囲**：管理画面の回答テストは、LINE の受信時と同じ回答処理（`generateAnswer`・出力の検査）を通るが、**LINE を経由していない**。LINE 経由の AI 自動返信（自動応答 ON・返信 live）は未検証
- **後片付け**：テスト後、`ADMIN_ANSWER_TEST_MODE` と `ANTHROPIC_API_KEY` を Production から削除して再デプロイ（Ready）。2026-11-14 20:33 JST に読み取り専用で確認：環境変数 11 項目（両変数なし）、自動応答 OFF、返信は dry-run（最新のデプロイ後の定期通知のログ）、管理画面の書き込みは無効（`ADMIN_WRITE_MODE` なし）、本番 DB の 13 項目と登録内容の指紋はテスト前と同じ（回答テストは会話ログ・AI 利用枠に記録しない）
