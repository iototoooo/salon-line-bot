### 6.3 実機テストの記録（2026-11-12）

- **目的**：オーナー通知（WBS 2.5）が実際の LINE に届くことの確認。
- **環境**：ローカルの開発サーバー（`npm run dev`）＋ Cloudflare の一時 URL（無料）。テスト用 LINE 公式アカウント（友だち 1 人＝テスト担当者のみ）。Supabase（Ref `dnortggovlwgcdeoadbf`）。Vercel・Claude API は使用せず、費用 0 円。
- **設定**：`LINE_REPLY_MODE=live`・`LINE_RESPONDER=ai`（テスト中のみ）、`bot_enabled=false`、`ANTHROPIC_API_KEY` は空。通知先 `owner_line_user_id` を登録（テスト用公式アカウントの友だちであることを読み取り専用で確認済み）。
- **手順**：テスト担当者の LINE から 1 通送信。
- **結果**：
  - 定型文の返信と、オーナー通知「【要対応】LINE のお問い合わせ 1 件」の **2 通が届いた**（テスト担当者が目視で確認）。
  - サーバーのログ：Webhook 受信 200（約 1.2 秒）、`[owner-notify] sent 1 item(s), attempt=1`。エラーなし。ログに LINE ユーザー ID・本文なし。
  - DB：`line_webhook_events` は done・返信 sent・通知済み。`conversations` は bot_off・reply・要対応・通知済み。`owner_notification_batches` は sent（1 回目で成功）。`ai_usage_reservations` は 0 件（Claude は呼ばれていない）。
